# 霓虹贪吃蛇

一个无需构建、无需依赖的单文件贪吃蛇小游戏，打开 [index.html](./index.html) 即可运行。

## 玩法

- 使用方向键或 \`WASD\` 控制蛇移动。
- 吃到粉色能量点会增加 10 分，等级越高速度越快。
- 撞到边界或自己的身体后游戏结束。
- 手机端可以滑动棋盘或点击方向按钮操作。
- 最高分会保存在浏览器的 \`localStorage\` 中。

## 快捷键

- \`空格\`：暂停 / 继续
- \`Enter\`：开始或重新开始

## 本地运行

直接双击 \`index.html\`，或在仓库目录启动任意静态文件服务器：

\`\`\`bash
python3 -m http.server
\`\`\`

然后访问 \`http://localhost:8000\`。
